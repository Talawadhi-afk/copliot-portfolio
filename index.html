How Microsoft Copilot Assisted

Microsoft Copilot assisted me throughout the development process. First, it helped generate the basic HTML structure for the portfolio website, including sections such as About, Projects, Skills, and Contact. Next, it helped improve the CSS by suggesting colors, spacing, typography, cards, gradients, rounded corners, and hover effects to make the design look more professional.

Copilot also provided responsive design suggestions using flexible layouts and media queries, allowing the website to work well on mobile, tablet, and desktop screens. In addition, it helped add interactive UI/UX features such as a mobile navigation menu, dark mode button, project filters, modal popups, and form validation. Finally, Copilot helped polish the overall website so it is more user-friendly, modern, and ready to publish on GitHub Pages.
